5Global ⌘ shortcuts fire while you type. New combos must not clash with text editing (⌘A, ⌘Z, ⌘C/V/X, ⌘←/→, ⌘Backspace) or the browser (⌘L, ⌘T, ⌘W).

Every shortcut in one place, with Esc spelled out so Stop is never a surprise.

  1. 1
    Global hotkeys dataThe four useHotkeys combos. ⌘J is ignored while busy; the row dims then. Labels match the dock tooltips.
  2. 2
    Composer keys dataEnter and Shift+Enter, slash menu arrows and Tab, IME composition ignored. ↑ on an empty composer pulls the last queued message back to edit (client-kept queue).
  3. 3
    Esc order deriveOne handler walks the stack: menu, goal mode, popover/panel, then stop. Stop only fires with nothing else open, so a stray Esc can’t kill a turn behind a menu.
  4. 4
    Sequence keys derive newg n and ? are unmodified, so they must skip inputs, textareas and contenteditable. useHotkeys has no focus filter today and needs one for these.
  5. 5
    Clash rule derivehotkeyCombo ignores Shift and Alt and calls preventDefault on match, so any new mod-key steals it from the textarea. Prefer unmodified keys outside fields.
