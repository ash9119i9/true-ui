    One polite region deriveNewText is derived from the status pill: turn running, a new PendingRequest, turn completed. Debounced so a burst of steps doesn't repeat "Working". Errors that need action use role="alert".
  2. 2
    Focus order deriveDOM order matches visual order. A new request does not steal focus; mod+J jumps to it. Global hotkeys stay live while typing, and Esc follows the fixed order from the composer spec.
  3. 3
    Reduced motion deriveprefers-reduced-motion swaps shimmer for a static dot, the pulse for a solid badge, and turns transitions off. The spinner stays as a static ring so "busy" is still visible.
