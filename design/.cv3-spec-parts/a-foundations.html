Foundations

This part defines every token the other parts reference: color, type, spacing, layout constants, radii, shadows, z-index, motion, breakpoints and icons. It also sets the CSS file layout and how the legacy app/*.css files are retired. Values that exist in styles/v2/tokens.css or truex-design-spec.html are tagged exists. Tokens that only name a literal already in the CSS are derive. Anything else is proposal with a decision id.

Source of truth today: frontend/styles/v2/tokens.css (copied from the design spec Appendix) and literal values across styles/v2/*.css (schema §8). All new tokens in this part go into tokens.css. Components never use a literal hex, px spacing step, z number or duration once their surface is ported.

1. Color tokens

Theme mechanism

existsP0 lib/use-theme.ts · app/layout.tsx (THEME_BOOT_SCRIPT) · styles/v2/tokens.css

Light is the :root default. Dark applies from the system preference unless the user forced light, or from a forced data-theme="dark". Keep this mechanism unchanged in v3.

Anatomy

Light
:root { color-scheme: light; … }
System dark
@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { … } }
Forced dark
:root[data-theme="dark"] { … }, identical values to the media block
Storage
localStorage["truex-theme"] = "" | "light" | "dark". Empty follows the system.
Boot
THEME_BOOT_SCRIPT inlined in <head> before paint. <html suppressHydrationWarning>.
Toggles
Topbar theme button and account menu item.

Data

type ThemePref = "" | "light" | "dark";   // localStorage["truex-theme"]
// write(): sets or removes document.documentElement.dataset.theme
// subscribes to matchMedia("(prefers-color-scheme: dark)") changes

Behavior

  • Every new token in this part is declared in all three blocks. A token left out of the dark blocks keeps its light value in dark, so only leave one out on purpose (brand ramp, tints).
  • The two dark blocks must stay byte-identical. Add a lint check in CI (proposal, D-NEW: dark block parity check; default: a unit test that parses tokens.css and diffs the two blocks).
  • Fixed-in-both-themes colors stay fixed by design: agent badge (#FFFFFF bg, #1F2A30 text), .strap mixes, celebrate scrim rgb(12 15 17 / 78%) with text #F4F7F8. They become named tokens in Agent tints.

Acceptance

  • No theme flash on reload with truex-theme="dark" and a light OS setting.
  • Clearing the preference follows the OS live, without reload.
  • The two dark blocks in tokens.css contain the same declarations.

Reduced motion

v3 turns animations and transitions off, instead of shortening them to 0ms as the global rule in tokens.css does today. Infinite animations with 0ms duration stop in an arbitrary frame, which can leave ag-pulse at half opacity.

@media (prefers-reduced-motion: reduce) {
  :root { --dur-1: 0s; --dur-2: 0s; --dur-3: 0s; --dur-4: 0s; --dur-5: 0s; }
  *, *::before, *::after { animation: none !important; transition: none !important; scroll-behavior: auto !important; }
  .pulse { box-shadow: none; }           /* solid dot, label carries meaning */
  .spinner { border-right-color: transparent; }  /* static ring with a gap */
  .shimmer { background: var(--surface-3); }
}
