Session panel and insights

The session panel is the right-hand aside that holds the per-session views: Activity, Goal, Agents, Plan, Insights and a new Changes tab. This part also owns the three observability levels that live in the chat: the receipt under each answer (level 1), the trace card (level 2) and the developer details (level 3), plus every chart, meter and formatter they share. v3 keeps today's data and math, puts the plain-language outcome first, turns privacy findings and usage limits into actions, and adds a This turn / Session scope to the panel.

Source of truth for today's values: chat-ui-schema.md §6 (observability) and §3.15 (SessionActivity). Target design: design/.cv3-parts/obs.html; the Activity and Plan tab designs come from the r2 panel boards (design/.cv2r2-parts/panel.html), which v3 kept. Existing spec values: truex-design-spec.html #s-panel, #s-activity, #s-plan, #s-insights. The Goal tab and goal strip are specified in Goal strip and the Agents tab in Agents. The turn state every status surface reads is deriveTurnState() in Shell.

Token rules for this part: text under 13px uses --ink-2. Chart series use --series-1..3 and --series-other; gridlines --chart-grid; axis text --chart-axis. Semantic states use --warn/--warning-bg/--warning-text, --bad/--bad-bg and --ok/--ok-bg. Motion uses --dur-* and --ease-*. All of these come from Foundations. Raw values quoted below are today's CSS; the named token replaces each at the same value.

Token math (exists)

  • splitTokens(u): cached = clamp(cachedInputTokens, 0, inputTokens); newInput = inputTokens − cached; reasoning = clamp(reasoningOutputTokens, 0, outputTokens); output = outputTokens − reasoning; total = sum of the four. Null gives zeros.

  • turnCounts(t) adds usage and helperUsage field by field. turnTokens(t) = turnCounts(t)?.totalTokens ?? 0.
  • contextFraction(u) = contextUsedTokens / contextWindow, clamped 0..1; null when no window or contextUsedTokens === null.

Session summary (exists)

  • summarize(traces): turns = count; avgTotalMs = mean of numeric totalMs; p95TotalMs = percentile(times, .95) nearest rank (sorted[ceil(p·n)−1]); main token fields summed from usage; helperTokens sums helperUsage.totalTokens; privacyFindings sums counts.
