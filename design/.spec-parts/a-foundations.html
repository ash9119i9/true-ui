Overview

This page is the invite landing for truex agents. Someone opens an invite link, sees who invited them and to which workspace, and joins. The source prototype is design/join-tenant-v3-capabilities.html.

The page has one job: accept the invite by entering your name and pressing Join. Everything else supports that job or explains what the person gets after joining.

Two panes

  • Left, the invitation (.left): brand header, a one-line "who invited you" row with an expiry pill, the headline "Take your seat at Northwind Labs", and the join card. The join card holds a 3-step progress checkup, the locked work email, the name input, the Join button and fine print.
  • Right, the capabilities board (aside.right): a dotted specimen sheet with eight numbered objects, one per truex capability, and a legend underneath. The board is decorative (aria-hidden="true"). The legend is the readable version. Specimen 07 ("You") mirrors the name as it is typed.

Prototype-only controls

  • The "Preview state" segmented control in .foot (Valid invite / Expired / Already a member) is a design-review tool. Do not ship it. In production the state comes from the invite lookup.
  • The theme segmented control in the header (Auto / Light / Dark) is also a review tool. It mirrors the app's useTheme() hook in app.tsx: same localStorage key "truex-theme", value "" for Auto, "light" or "dark", applied as data-theme on <html> (removed for Auto). In production, reuse useTheme() and do not add a second theme store.
  • The ?theme=light|dark query param override is prototype-only (used for screenshots). Do not ship it.

Board sizing

The board is sized by two nested container queries. .board-wrap is a size container that fills whatever height is left between the head and the legend. The board takes the largest width that fits both axes and caps at 560px: min(100cqw, 560px, 100cqh * 5 / 5.4), with aspect-ratio: 5 / 5.4. The board is itself an inline-size container, so every specimen position, size and font inside it is in % or cqw and scales with the board. Specimen positions are absolute percentages of the board.

On desktop the page itself must never scroll. .split is locked to 100dvh and the right panel is overflow: hidden, so the board shrinks to fit. Only the left column may scroll, and only on short viewports.

Color tokens

Theme selectors

Tokens are defined in three states, the same pattern as index.html:

  1. :root holds light values and color-scheme: light.
  2. @media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) { ... } } applies dark values when the OS is dark and the user has not forced light (Auto).
  3. :root[data-theme="dark"] { ... } applies the same dark values when the user forces dark, regardless of OS.

Blocks 2 and 3 are identical and both set color-scheme: dark. data-theme="light" needs no block of its own: it only disables block 2.
