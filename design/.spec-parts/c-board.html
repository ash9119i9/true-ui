  • The board is a 5:5.4 box (5:6.4 under 520px). It fits the free space of .board-wrap and never exceeds 560px wide.

  • Text and small controls use max(Npx, Mcqw) so they never shrink below a readable pixel floor, for example max(12px, 2.8cqw) on the timer.

Fix before shipping: h >> 4 is a signed shift. When h is 231 or more, the result is negative, % 4 returns -3 to 0, and b can equal a or become a negative index (var(undefined), so the second aura color disappears). Use (h >>> 4) % 4. Then b is always one of the four colors other than a.

Parallax

  • Listener: pointermove on .right (the whole panel), measured against the board rect.
  • Offset: --px = ((clientX - rect.left) / rect.width - .5) * -10, and the same for --py on Y. Range is -5 to 5 at the board edges, larger outside the board. Written on #board as unitless numbers.
  • Each .sp moves by --px * --d px and --py * --d px, so items with higher --d (04 at 1.6) move more than the bars (.4). Movement is opposite to the pointer.
  • Easing: transition: transform .8s cubic-bezier(.2,.8,.2,1).
  • pointerleave on .right resets both to 0.
  • Not attached when prefers-reduced-motion: reduce matches at load. On touch, pointermove only fires during a drag.
if (!matchMedia("(prefers-reduced-motion: reduce)").matches) {
  board.closest(".right").addEventListener("pointermove", (e) => {
    const r = board.getBoundingClientRect();
    board.style.setProperty("--px", (((e.clientX - r.left) / r.width) - .5) * -10);
    board.style.setProperty("--py", (((e.clientY - r.top) / r.height) - .5) * -10);
  });
  board.closest(".right").addEventListener("pointerleave", () => { board.style.setProperty("--px", 0); board.style.setProperty("--py", 0); });
}
