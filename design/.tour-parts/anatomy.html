The hole follows the pill at any width. Everything else sits under one scrim, so the page still reads as the app.

  1. 1
    Ring2px in --spot-ring, 6px outside the target, same radius as the target (999px for pills, 14px for cards). It hugs the element so the user sees exactly what is being named..spot.round.inset · data-tour="status-pill"
  2. 2
    GlowAn 8px soft band in --spot-glow just outside the ring. It separates the target from the scrim on busy screens without adding a second border.box-shadow 0 0 0 8px var(--spot-glow)
  3. 3
    Breathing pulseA second ring grows to 106% and fades out over 2.4s, looping. Under prefers-reduced-motion it is off and the static ring stays..spot::after · @keyframes breathe
  4. 4
    ScrimLight rgb(22 34 41 / 48%), dark rgb(0 0 0 / 64%). Dark goes deeper because the app surfaces are already close to black. Clicks on the scrim do nothing, so a stray click never ends the tour.--scrim token
  5. 5
    Click-throughThe hole is real. On Try steps the target stays clickable, so the user picks an agent or sends the prompt in the actual app. On Look steps clicking the target also works, it just does not advance.NewTourLayer · pointer-events on the hole
  6. 6
    BeaconA 12px dot for small targets the ring would swamp, like the send button on step 6. Pulses at 1.8s, also off under reduced motion. If no target is found after 3s the spot and beacon drop and the card centers..beacon
