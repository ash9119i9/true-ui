Step config

type TourStep = {
  id: string;
  chapter: 1 | 2 | 3;
  kind: "look" | "try" | "wait";
  target?: string;          // data-tour value, none = centered card
  placement?: "below" | "above" | "left" | "right" | "center";
  title: string;
  body: string;
  prepare?: (app: TourApi) => void;   // put the app in state first
  waitFor?: () => boolean;             // polled; 3s then centered card
  advanceOn?: "send" | "pick-agent" | "click";
};

const steps: TourStep[] = [

Build phases

  1. Anchors. Add the twelve data-tour attributes and the DockItem.tour field. No visible change, safe to merge alone.
  2. Engine. useTour: step index, truex-tour storage, prepare, waitFor, advanceOn, the 3s fallback and the hotkey pause.
  3. Layer. TourLayer: spotlight from getBoundingClientRect with ResizeObserver and scroll updates, coach placement with flip, bottom sheet under 640px, the new tokens.
  4. Content and entry. Eleven steps of copy, auto-start on first visit, Take the tour in UserMenu, the resume chip, then a pass in light and dark at 400, 1024 and 1440 wide.
