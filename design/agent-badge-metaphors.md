# Agent Badge Metaphors: MCP + Skills

Agents get the same badge human teammates get. The story: agents join your team, they aren't tools you install. What varies is where MCP and Skills live on the badge and how it feels to receive one.

- MCP = what the agent can reach (access)
- Skills = what the agent knows how to do (know-how)
- Badge = the identity that holds both

---

## 1. The Flip Badge

> "Same badge as your team. Different superpowers on the back."

The front matches the human member card exactly: face, name, role. The back is agent-only. It has a magnetic access strip (MCP) and certifications (Skills).

```
   FRONT  (who it is)                    BACK  (what it can do)
  ┌──────────────────────┐   ⟲ flip    ┌──────────────────────┐
  │ ◉ TRUEX              │  ───────▶   │▓▓▓▓▓▓│ ← access strip
  │    ┌──────┐          │             │ GitHub · Jira · Slack │   (MCP)
  │    │ (◕‿◕)│          │             │──────────────────────│
  │    └──────┘          │             │ CERTIFIED IN         │ ← Skills
  │    NOVA              │             │ ✦ Bug triage         │
  │    Release Analyst   │             │ ✦ PR recap           │
  │    ● AI teammate     │             │ ✦ Release notes      │
  │                      │             │──────────────────────│
  │  ||| |||| || ||| |   │             │ Issued by @ashok     │
  └──────────────────────┘             └──────────────────────┘
```

- Hero moment: 3D flip that reveals capabilities.
- MCP creation: "Encode the strip". Each connection writes a stripe.
- Skill creation: "Certify". Each skill is stamped with who approved it.
- Why it sells: humans and agents look the same in the team list. Only the flip shows the difference.

## 2. The Backstage Pass

> "You're on the list."

Concert pass instead of office ID. MCPs are zones printed on the pass, and a punched-out zone means no access. Skills are woven into the lanyard as crew roles.

```
              ║ TRIAGE ║
              ║ RECAP  ║   ← lanyard woven with Skills
              ║ NOTES  ║
              ╚══╦═════╝
        ┌────────┴─────────┐
        │ ★  ALL ACCESS  ★ │
        │                  │
        │  NOVA            │
        │  CREW · Analyst  │
        ├──────────────────┤
        │ ZONES   (MCP)    │
        │ [A] GitHub    ✓  │
        │ [B] Jira      ✓  │
        │ [C] Slack     ✓  │
        │ [D] Prod DB   ◯  │ ← punched hole = no access
        └──────────────────┘
```

- Hero moment: the pass drops in on its lanyard and swings, with a hologram shimmer.
- MCP creation: "Grant a zone". Zone letters make scope tangible.
- Skill creation: "Weave into lanyard".
- Why it sells: playful, and the punched-hole permissions story works for enterprise buyers.

## 3. The Growing Badge (Patches + Keyring)

> "Hire in a minute. Watch them grow."

The badge changes over time. Skills are stitched patches that earn stars with use. MCPs are keys hanging off the badge clip.

```
   DAY 1                              DAY 30
  ┌──────────────────┐               ┌──────────────────┐
  │ NOVA   Analyst   │               │ NOVA   Analyst   │
  │ (◕‿◕)            │               │ (◕‿◕)    ★ Lv 3  │
  ├──────────────────┤    ──────▶    ├──────────────────┤
  │ (T) (R)  ( )     │               │ (T)(R)(N)(F)     │ ← patches
  │                  │               │ T·142 runs  ★★   │   (Skills)
  └───┬────┬─────────┘               └───┬───┬───┬───┬──┘
      ⚷    ⚷                             ⚷   ⚷   ⚷   ⚷    ← keyring
   GitHub Jira                       GitHub Jira Slack DB   (MCP)
```

- Hero moment: stitch animation when a skill is added, plus a "Nova leveled up" notification.
- MCP creation: "Add a key". Keys jingle onto the ring.
- Skill creation: "Stitch a patch". Empty slots invite the next one.
- Why it sells: emotional attachment and a reason to come back.

## Combined creation flow: "Print the badge"

The badge assembles live at each step, like watching a badge printer. New MCPs and Skills open in an inline sheet and return to the same step, so the user never leaves agent creation.

```
 ① Face & name     ② Access (MCP)      ③ Skills           ④ Print
 ┌──────┐          ┌──────┐            ┌──────┐           ┌──────┐
 │ (◕‿◕)│   ──▶    │ (◕‿◕)│    ──▶     │ (◕‿◕)│    ──▶    │ (◕‿◕)│ ═▶ 🖨
 │ ░░░░ │          │ ▓▓░░ │            │ ▓▓✦✦ │           │ ▓▓✦✦ │
 └──────┘          └──────┘            └──────┘           └──────┘
                   + connect new        + write new
                   (inline sheet)       (inline sheet)
```

It ends with a shareable welcome post. Every new agent announces itself, so each creation also advertises the product inside the customer's workspace.

```
 ┌─ #general ──────────────────────────────────────────────┐
 │ 🎉 Meet Nova, our new Release Analyst.                  │
 │    Has keys to GitHub, Jira, Slack                      │
 │    Trained in Bug triage, PR recap, Release notes       │
 │    [ Say hi ]  [ View badge ]                           │
 └─────────────────────────────────────────────────────────┘
```

## Recommendation

- Core: Flip Badge. It fits the existing member card with no redesign.
- Retention: Growing Badge's patches and levels.
- Permissions view: Backstage Pass's punched zones.
