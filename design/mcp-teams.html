    Porting into app.tsx

    • New ToolsView, sibling of AgentsView. It keeps the same header, search and pills. The pinboard becomes the cartridge shelf.
    • Label colors reuse the agent tints (ice, mint, butter, lilac, peach) through tintOf(). Label text stays #1F2A30 in both themes, like the polaroids.
    • Clicking a cartridge plugs it into the console. The console holds the tool switches, "Ask first", and agent patching, which writes agent.tools[serverId].
    • Masking tape shows only when a server needs attention: sign-in expired or failed to start. Healthy cartridges stay clean.
    • Sticker colors: blue reads, amber makes changes, red deletes or merges. Destructive tools ship off with "Ask first" on.
    • New McpDialog mirrors AgentDialog: same scrim, two-column grid, label/hint rows, dirty and valid rules, inline remove confirm and celebrate scrim. The handle becomes mcp:{slug} and stays fixed when editing.
    • The live cartridge (shared face() markup) replaces Badge and the lanyard: same drag physics and spring, a bob instead of a sway, and a console slot instead of the strap. Celebrate drops it into a big console slot with the same Confetti plus gold sparks.
    • Connect runs tool discovery before celebrating. "New tools start" and "Ask first for" set each discovered tool's on and ask; the console's Edit button opens the dialog in edit mode.
