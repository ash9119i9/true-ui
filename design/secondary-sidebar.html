◎ Goal✦ Tools qlik↑

Compact 360px

Default. Scanning lists: activity feed, agent roster, plan, insights.

  • Agent rows show name + short role, never the raw prompt.
  • Status as an icon, so step text gets the full width.

Detail 560px

Opens automatically when one agent or plan step is opened. Back or Esc returns to compact.

  • Output reads at a real line length (about 60 characters).
  • Tables in agent output fit without sideways scroll.

Custom 320–720px

Drag the left edge. Width is remembered separately for list and detail modes. Double-click the edge to reset.

  • Arrow keys on the focused edge resize in 20px steps.

Layout rules

  1. Chat never drops below 640px. The thread is 740px max, so 640 keeps messages readable.
  2. If opening detail would break that, the left sidebar collapses and comes back when detail closes.
  3. If the chat is still too narrow (small laptops, phones), the panel floats over the chat as a drawer instead of squeezing it.
  4. Chat and panel are linked: clicking a helper row in chat opens that agent, and hovering an agent in the panel lights its row in chat.

  • Does Insights need per-agent cost in dollars, or tokens only?
